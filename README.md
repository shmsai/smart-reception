# Smart Reception

A bilingual Arabic/English reception and appointment management system.

## Problem

Reception teams need a simple way to manage appointments, visitor check-ins, queues, and visitor status.

## Planned Features

- Appointment management
- Visitor check-in
- Queue management
- Receptionist and admin roles
- Arabic and English interface
- Basic reports

## Status

Planning and initial setup.
